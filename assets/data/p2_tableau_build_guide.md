# Tableau 构建指南 · 医药零售连锁扩张质量与资金效率分析

> 目标：用 2–3 小时在 Tableau Desktop / Public 中复现这个项目。完成后简历里写 “Tableau” 就完全站得住。
> 数据文件：`retail_clean.csv`（30 行 = 5 家公司 × 6 年，已含清洗与口径统一后的指标）

## 一、数据连接

1. Tableau → 连接 → 文本文件 → 选择 `retail_clean.csv`
2. 检查字段类型（否则排序会错）：

| 字段 | 类型 | 角色 |
|---|---|---|
| 公司简称 | 字符串 | 维度 |
| 年份 | 数字（或日期-年） | 维度 |
| 营业收入、营业成本、净利润、销售费用、商誉、净资产 | 数字（小数） | 度量 |
| 营收增速、毛利率、净利率、销售费用率、存货周转天数、应收周转天数、营运资金占用天数、商誉占净资产、总资产周转率、ROE | 数字（小数） | 度量 |

**重要做法（面试可讲）**：需要“期初值”的指标（周转天数、同比增速）已经在数据层用 SQL 的窗口函数 `LAG` 算好，Tableau 只做展示。**把口径复杂的指标固定在数据层，避免同一指标在 SQL 和 BI 两处口径不一致** —— 这是数据治理里很实用的一条原则。

## 二、建议新建的计算字段

在 Tableau 中新建以下字段（用于展示层）：

```
// 1. 风险等级分类
IF [商誉占净资产] >= 0.8 THEN "高风险"
ELSEIF [商誉占净资产] >= 0.5 THEN "中风险"
ELSE "低风险"
END

// 2. 增长类型标签
IF [净利增速] < 0 AND [营收增速] > 0 THEN "增收不增利"
ELSEIF [净利增速] > 0 AND [营收增速] > 0 THEN "量利同增"
ELSE "其他"
END

// 3. 营收规模档位（用于颜色分组）
IF [营业收入] >= 200 THEN "200 亿以上"
ELSEIF [营业收入] >= 100 THEN "100–200 亿"
ELSE "100 亿以下"
END
```

## 三、四个工作表（Sheet）设计

### Sheet 1｜扩张与盈利背离（散点图）
- 列：`营收 CAGR`（需先做计算：见下）
- 行：`净利 CAGR`
- 详细信息：`公司简称`
- 颜色：`增长类型标签`
- 参考线：X = 0、Y = 0（十字线，一眼看出谁在“增收不增利”象限）

> CAGR 计算（Tableau 写法，用 LOD 取首末年）：
> ```
> {FIXED [公司简称] : MIN(IF [年份]=2020 THEN [营业收入] END)}
> ```
> 名为 `营收_2020`，同理建 `营收_2025`，再：
> ```
> 营收 CAGR = (([营收_2025] / [营收_2020]) ^ (1/5)) - 1
> ```

### Sheet 2｜商誉风险（条形图 + 参考线）
- 行：`公司简称`（按 `商誉占净资产` 降序排列）
- 列：`商誉占净资产`
- 颜色：`风险等级分类`
- 标签：显示值（百分比格式）
- 参考线：0.8（高风险阈值）

### Sheet 3｜营运资金效率（堆叠条形图）
- 行：`公司简称`
- 列：`存货周转天数`、`应收周转天数`（堆叠）
- 标签：显示合计天数
- 排序：按合计降序

### Sheet 4｜费用结构与盈利（组合图）
- 列：`公司简称`
- 行：`毛利率`、`销售费用率`、`净利率`（三度量并排柱）
- 说明：直观展示“约 35% 的毛利被 21%–29% 的销售费用吃掉”

## 四、仪表板（Dashboard）布局

```
┌─────────────────────────────┬─────────────────────────────┐
│  KPI 卡片区（文本对象）        │  筛选器：年份（2020–2025）    │
│  营收合计 / 增速 / 商誉占比    │                             │
├─────────────────────────────┼─────────────────────────────┤
│  Sheet 1 扩张与盈利背离        │  Sheet 2 商誉风险            │
├─────────────────────────────┼─────────────────────────────┤
│  Sheet 3 营运资金效率          │  Sheet 4 费用结构与盈利       │
└─────────────────────────────┴─────────────────────────────┘
```

**KPI 卡片**用 `文本` 对象 + 参数化计算字段实现，例如：
```
"样本合计营收：" + STR(ROUND(SUM([营业收入]), 1)) + " 亿元"
```

## 七、面试可能追问

- **为什么用散点图而不是柱状图？** 因为要同时看两个变量的关系（增长 vs 盈利），柱状图只能看单维度排名；散点图能直接定位“增收不增利”象限。
- **商誉占比为什么能当风险指标？** 商誉来自溢价并购，一旦标的业绩不达预期就要计提减值、直接冲减利润；占净资产比重越高，减值的杀伤力越大。
- **为什么周转天数放在数据层算？** 平均余额需要期初值，用窗口函数 `LAG` 在 SQL 里一次算准，避免 BI 层再用表计算重复实现、产生口径差。
