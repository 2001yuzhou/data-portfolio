# FineBI / Tableau 看板搭建指南（项目三）
## 页面 1：用户总览
- KPI：用户数、行为事件数、次日留存率、新品购买用户占比。
- 图表：性别、年龄、城市线级、会员等级分布；周浏览量趋势；浏览深度。
- 筛选：日期、性别、年龄、城市线级、会员等级。

## 页面 2：商品与人群偏好
- 图表：品类浏览量 Top10、品牌浏览量 Top10、品类订单量 Top10。
- 交叉表：年龄 × 性别 × 品类 Top3。
- KPI：新品购买用户占比。
- 业务解释：手机、外套、茶是主要流量入口；新品推广需要价格、评价和背书。

## 页面 3：用户运营
- RFM 分层图：重要价值、重要保持、重要发展、重要挽留等。
- 行为漏斗：浏览用户、加购用户、下单用户、浏览∩下单、加购∩下单。
- 互动率：关注/评论用户/浏览用户。
- 注意：订单用户/浏览用户规模比和真实交集转化率必须分开显示。

## 页面 4：店铺与类目
- 新老店 0 单占比、店均订单、中位数订单。
- 有效评分店铺的评分与浏览量散点图。
- 类目竞争：店铺数、平均订单、0单占比、Top3门店订单占比。
- 业务解释：高分不等于高流量，订单向头部门店集中。
