# 京东平台用户行为与运营策略分析
## 项目背景
电商竞争加剧，平台需要通过用户行为分析提升留存、商品运营和店铺经营效率。本项目以183,828条京东用户行为记录为基础，回答“用户是谁、偏好什么、是否忠诚、如何转化、店铺为何增长”五个问题。

## 项目目标
1. 用户画像与活跃规律。
2. 品类、品牌与新品偏好。
3. RFM用户分层。
4. 浏览、加购、下单与互动漏斗。
5. 店铺评分、新老店经营与类目竞争。
6. 输出可视化经营看板与业务建议。

## 数据与处理
- 数据窗口：2018-02-01 至 2018-04-15，共74天。
- 原始数据：183,828行×20字段；清洗后有效数据：183,827行，去重1条业务重复记录。
- 年龄、城市少量缺失保留为未知；店铺注册日期缺失单独标记。
- 店铺评分0/-1不作为真实评分参与评分分析。
- 订单数据没有成交金额，therefore RFM用购买品类数、品牌数、店铺数构造M值代理，不虚构GMV。

## 1. 用户画像与留存
- 男性用户占61.2%，女性占38.5%。
- 46-55岁和56岁以上用户合计占约76.3%。
- 三四线城市用户占比最高，平台用户呈现下沉和老龄化特征。
- 加权次日留存1.70%，每日新增用户的平均次日留存1.53%，用户粘性偏弱。

## 2. 商品与人群偏好
- 浏览量最高品类：Phone, Coat, Tea, Notebook。
- 浏览量最高品牌：Huawei, Apple, Lipton, Sumsung。
- 订单量最高品类：Coat, Tea, Necklace, Facial Essence。
- 46-55岁男性和女性用户中最常见购买品类均为Coat和Tea。
- 购买上市30天内新品的用户占比3.98%，用户整体偏成熟品牌和经典商品。

## 3. RFM用户分层
- M值采用购买品类数、品牌数、店铺数代理，按NTILE思路打分后分层。
- 用户结构以重要价值客户和重要保持客户为主，具体人数与占比见`rfm_segments.csv`。
- 建议：高价值客户做会员留存，中价值客户做复购频次提升，低价值客户用低成本首购或唤醒策略。

## 4. 行为漏斗
- 有浏览记录用户：124,433人；下单用户：10,652人。
- 订单用户与浏览用户规模比：8.56%；但两者真实交集仅1,094人，交集转化率0.88%。
- 直接购买用户占订单用户的99.70%，购物车不是必经环节。
- 加购且下单用户32人，占加购用户1.09%；加购更适合被理解为收藏/比价工具。
- 互动率4.87%，用户内容互动较弱。

## 5. 店铺运营与类目竞争
- 有效评分店铺5,211家，评分缺失店铺875家。
- 有效评分店铺中评分与浏览量相关系数-0.012，高分不等于高流量。
- 全店铺0单占比59.25%，新老店中位数订单均为0，流量和订单向头部集中。
- 类目竞争按店铺数、平均订单、Top3门店订单占比计算。户外运动、电子产品Top3集中度较高，食品、美妆等类目门店更多且份额更分散。

## 6. 可视化看板
建议用FineBI/Tableau搭建四屏看板：
1. 用户总览：用户数、性别、年龄、城市、会员等级、留存。
2. 商品偏好：品类/品牌排行、人群偏好、新品接受度。
3. 用户运营：RFM分层、漏斗、互动率。
4. 店铺经营：评分与流量、新老店0单率、类目竞争。

## 7. 结论与建议
- 用户运营：对新用户加强首次访问后的二次触达，对重要保持用户做召回。
- 商品运营：继续强化手机、外套、茶等高频品类；新品推广必须叠加价格或背书，不宜只强调“新品”。
- 产品路径：突出“立即购买”，将购物车定位为收藏、比价和降价提醒工具。
- 店铺运营：不要单一追求评分，重点考核动销率、流量获取和头部店铺集中度。
- 类目策略：食品、美妆等门店多且分散；户外、电子等头部集中明显的类目更适合打造爆款切入。
